# Glory of Rome

## Overview
Glory of Rome is a mod for OpenBounty that replaces King's Bounty troops with Roman-themed units.

## Notes
- All internal IDs have been renamed to Roman names.
- Art files already used the Roman names.
- King's Bounty pack remains unchanged.

## Save Compatibility
Older saves using King's Bounty IDs may not load correctly. A migration path is recommended for future versions.
